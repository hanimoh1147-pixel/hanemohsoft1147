# HaneSoftwer

Initial implementation package for the HaneSoftwer service platform. See [README_AR.md](README_AR.md) for setup, Supabase SQL, owner provisioning, username-login Edge Function deployment, domain/DNS setup, and current limitations.

This package is not deployed and is not production-ready until the database schema is applied and tested, the owner account is configured, the domain is registered and connected, and a payment provider is integrated server-side.
